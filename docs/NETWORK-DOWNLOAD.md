# 网络下载

手机版内置「网络下载」面板（顶栏下载图标），可以从链接下载音频并自动入库播放。

> 合规提示：请只下载你有权使用的内容。下载他人作品可能受到版权法与平台协议的限制；
> 本项目不提供内容源，不绕过登录、会员或付费限制，也不对下载内容的合法性作任何保证。
> 与哔哩哔哩无隶属或授权关系（另见 [`BILI-CACHE.md`](BILI-CACHE.md)）。

## 使用步骤

1. 顶栏点「网络下载」；
2. 粘贴链接，点「解析」：
   - **音频直链**：`https://…/song.mp3`、`.m4a`、`.flac`、`.ogg`、`.opus`、`.aac`、`.wav` 等；
     应用先按扩展名判断，必要时用 `HEAD` 检查 `Content-Type`；
   - **B 站视频链接**：`https://www.bilibili.com/video/BV…`、`https://b23.tv/…`、`av…`；
     应用解析标题/作者/封面并取音频流（受视频权限、地区与登录状态限制，失败时会提示改用缓存导入）。
3. 确认解析结果（标题/作者/时长/封面预览），点「开始下载」；
4. 下载进度实时显示；完成后自动刷新曲库，出现在「下载音乐」来源。

## 技术细节

- 下载在原生后台线程执行，最多同时一个任务；支持跟随 301/302 重定向、断点续传（`Range`）、
  失败自动重试一次；文件名取 `Content-Disposition` 或 URL 末段，并清洗非法字符与路径穿越。
- 需要鉴权的 CDN（例如 B 站音频）会带上 `Referer: https://www.bilibili.com/` 与移动端 UA。
- 下载目录：应用私有 `files/downloads/`，卸载即清除；下载完成后触发曲库重扫。
- 单个文件没有硬性大小上限，但受设备剩余空间限制；进度事件包含已接收/总字节数。
- 浏览器开发模式下没有原生下载线程，面板会提示「在 App 内可用」。

## 历史记录

面板保留最近 20 条解析/下载记录（localStorage），可点击重新解析或重试。
清空 App 数据会同时清空历史记录与已下载文件。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 解析失败 | 链接不是音频、需要登录、地区限制或 CDN 拒绝；可尝试浏览器打开确认 |
| 下载卡住 | 网络不稳定；取消后重试，已下载部分会保留并在重试时续传 |
| 下载完成但无法播放 | 源文件不是浏览器支持的编码（如 DRM/加密流）；应用会提示格式不支持 |
| B 站链接解析失败 | 常见于需要登录/大会员的高清音轨；改用「B 站缓存」导入自己的缓存 |
